# LPJ-GUESS modelling of Chinese fir plantations in Lishui, Zhejiang

Dynamic vegetation modelling of Chinese fir (*Cunninghamia lanceolata*) plantation carbon
dynamics in Lishui, southern China (representative cell 119.75°E, 28.25°N), with
LPJ-GUESS **r13130** (forestry module), simulating **1901–2100**.

**Research question.** How do future climate change, CO₂ fertilisation, forest
management, and single extreme heat seasons jointly determine the carbon balance of fir
plantations?

## Key findings (October 2026)

- **CO₂ fertilisation dominates, climate offsets.** Fixed-CO₂ decomposition of cumulative
  NEP 2025–2100: climate contribution −2.5 to −5.8 kg C m⁻², CO₂ contribution +2.9 to
  +6.0 kg C m⁻². Under UKESM1-0-LL climate the two nearly cancel (BAU total −0.30).
- **Management shapes the stock.** Rotation length controls carbon storage (16 yr: 166,
  26 yr: 181, 36 yr: 199, no harvest: 294 t C ha⁻¹). Landscape BAU (w = 0.38 commercial
  share) accumulates 8.26 kg C m⁻² of ecosystem carbon over 2025–2100; harvest carbon
  payback time ≈ 22 yr.
- **Single heatwaves leave small, transient scars.** A +3 °C Jul–Sep pulse in 2045 cuts
  NPP by 15–27 % in the pulse year, but the 10-yr cumulative uptake loss is only
  ≈0.2 % of ecosystem carbon; a placebo (+0.01 K) pulse confirms these are not
  numerical artefacts. Age (stand structure) mediates 66–78 % of the management effect
  on NPP.
- **Natural regeneration after clearcut adds nothing** beyond the replanting already
  contained in the management regime (regen effect ≈ 0).

## Experiment design

| Factor | Levels |
|---|---|
| Elevation band (lapse-rate offset) | 200 / 500 / 800 m |
| Management (switch in 2025) | `bau26` (26-yr rotation) / `ext36` (36-yr) / `stop` |
| Heat parameter `pstemp_high` | 25 / 30 °C |
| GCM × SSP | GFDL-ESM4 / UKESM1-0-LL × SSP1-2.6 / SSP5-8.5 |
| Planting phase | 0–3 (7-yr offsets, controls age structure) |
| Pulse (extreme season) | `hot3y2045` / `hot3y2075` (+3 °C Jul–Sep), `plcy2045` (+0.01 K placebo) |

Historical climate: ISIMIP3a GSWP3-W5E5 obsclim (daily 0.5°, 1901–2019). Future:
ISIMIP3b (2020–2100). CO₂: ISIMIP3a obsclim 1850–2021 + ISIMIP3b 2022–2100. N
deposition: Lamarque RCP6.0 for all scenarios (common-N design). Soil code 3.

## Environment

- LPJ-GUESS r13130 (Zenodo 14411974) + libraries from 4.1.1 + one-line patch in
  `cfinput.cpp` (see `docs/patches/`)
- Ubuntu 22.04, Python 3.10+, `pandas`, `numpy`, `netCDF4`, `matplotlib`, CDO 2.0.4
- Path convention: all scripts assume the project root is `~/lpjg_lishui` (see `BASE`
  at the top of `run_main.py`); adjust if you clone elsewhere.

## Workflow

1. `scripts/get_data.sh` then `scripts/get_future.sh` → `data/climate*`, `data/co2/`
2. `python scripts/make_design.py` → `design.csv`
3. `python scripts/run_main.py` → `runs_main/` (288 runs; pulses generated in-run)
4. `python scripts/co2fix.py` → `runs_co2fix/` (fixed-CO₂ attribution)
5. `python scripts/stop_regen.py` → `runs_regen/` (regeneration sensitivity)
6. `python scripts/export_for_r.py` → `export/` CSVs + `export.tar.gz`
7. `python scripts/analyze_pulse_detail.py` → `pulse/` metric tables

See `docs/LOG.md` for the full history of decisions, calibrations and open issues.

## Data sources & calibration targets

- Li et al. (2016) *Chin. J. Plant Ecol.* 40:354–363 — Zhejiang biomass/soil carbon
- LY/T 2908-2017 and Zhejiang provincial rules — rotation-length policy constraints
